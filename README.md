# EFL 3PL Warehouse Inventory

PHP + MySQL app for the EFL 3PL Web Development & Design assignment.

## Setup (WampServer)

1. Copy project to C:\wamp64\www\efl-3pl-web-assignment
2. Start WAMP (icon green)
3. phpMyAdmin → Import sql/schema.sql
4. Open http://localhost/efl-3pl-web-assignment/

## Features

- Register / login with password_hash
- Product create, read, update, delete
- Products JOIN suppliers
- AJAX product search
- jQuery form validation
